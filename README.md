# 🚀 Developer Portfolio

Professional və müasir developer portfoliosu - React, Vite, Tailwind CSS və Framer Motion istifadə edilərək hazırlanıb.

## ✨ Xüsusiyyətlər

- ⚡ **Lightning Fast** - Vite ilə sürətli development və build
- 🎨 **Modern UI** - Aceternity UI və Magic UI-dan ilham alınmış komponentlər
- 🌙 **Dark/Light Mode** - localStorage ilə tema qorunması
- 🌍 **Çoxdilli** - Azərbaycan, İngilis və Rus dilləri dəstəyi
- 📱 **Tam Responsive** - Bütün cihazlarda mükəmməl görünüş
- 🎭 **Smooth Animations** - Framer Motion ilə professional animasiyalar
- 📋 **Copy to Clipboard** - Email və digər məlumatları asanlıqla kopyalama
- ⚡ **Skeleton Screens** - Yüklənmə zamanı interaktiv loading effektləri
- 🎯 **Sticky Navigation** - Hər yerdən menyu access
- 🖼️ **Project Preview** - Proyekt şəkillərinin böyük görünüşü

## 🛠️ Texnologiyalar

- React 18
- Vite
- Tailwind CSS
- Framer Motion
- Lucide Icons

## 📦 Quraşdırma

1. Asılılıqları quraşdırın:
```bash
npm install
```

2. Development serverini başladın:
```bash
npm run dev
```

3. Production build:
```bash
npm run build
```

4. Production preview:
```bash
npm run preview
```

## 🎨 Özəlləşdirmə

### Şəxsi məlumatları dəyişdirin:

1. **Contact.jsx** - Email, telefon və digər əlaqə məlumatları
2. **Projects.jsx** - Öz proyektlərinizi əlavə edin
3. **Skills.jsx** - Bacarıqlarınızı və səviyyələri yeniləyin
4. **Education.jsx** - Təhsil məlumatlarınızı daxil edin

### Rəngləri dəyişdirin:

`tailwind.config.js` faylında tema rənglərini dəyişə bilərsiniz.

### Komponentləri əlavə edin:

`src/components/` qovluğuna yeni komponentlər əlavə edə bilərsiniz.

## 🎯 Xüsusiyyətlər

- **Sticky Navbar**: Həmişə görünən naviqasiya paneli
- **Language Toggle**: Azərbaycan, İngilis və Rus dilləri arasında keçid
- **Tracing Beam**: Scroll zamanı animated xətt effekti
- **Hover Cards**: Mouse hover zamanı interaktiv effektlər
- **Theme Toggle**: Dark və Light mode arasında keçid
- **Copy to Clipboard**: Məlumatları bir kliklə kopyalama
- **Skeleton Screens**: Yüklənmə zamanı professional görünüş
- **Responsive Design**: Mobil, tablet və desktop uyğunlaşma
- **Smooth Animations**: Framer Motion ilə axıcı keçidlər


## 🚀 Deploy

Vercel, Netlify və ya GitHub Pages-də deploy edə bilərsiniz:

```bash
npm run build
```

Build faylları `dist/` qovluğunda olacaq.
